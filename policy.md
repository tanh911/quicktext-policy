Privacy Policy for QuickText

Last updated: November 2026

1. Overview
QuickText ("we", "our", or "the extension") is a productivity extension designed to provide instant keyboard shortcut expansions. We believe strongly in user privacy and data minimization. QuickText operates as a local-first browser extension.

2. Information Collection and Use
QuickText does NOT collect, harvest, monitor, transmit, or sell any personal data, browsing history, or keystrokes.
- Text Snippets & Shortcuts: All abbreviations, titles, and text contents created by the user are stored strictly within the user's browser local storage (chrome.storage.local) and Google Chrome user-synchronized storage (chrome.storage.sync).
- Keystroke Monitoring: QuickText monitors keyboard inputs solely in active webpage input elements to detect user-configured shortcut triggers (e.g., "!mail"). The extension does not record, log, or store typed keystrokes beyond detecting the trigger string for immediate text replacement.

3. Network Communications & Data Transfer
QuickText operates entirely offline for its core functionality:
- No telemetry, analytics, or background tracking scripts are included.
- No user content or snippet data is ever transmitted to external servers or third-party tracking services.
- If the user voluntarily submits feedback or bug reports through the feedback dialog, only the user's submitted message, optional contact information, and browser environment diagnostics are transmitted directly via Formspree to the developer for bug resolution.

4. Permissions Justification
- storage: Used solely to store the user's custom shortcuts, preferences, and local expansion statistics.
- activeTab & Host Permissions (<all_urls>): Required to detect configured shortcut triggers in text fields across web pages and perform real-time text expansion.
- contextMenus: Enables the user to right-click highlighted text and quickly save it as a new shortcut.
- scripting: Used exclusively during installation/updates to inject the expansion script into already open tabs so users do not need to manually refresh them.

5. Third-Party Disclosures
We do not share, sell, rent, or trade any user information with any third parties or advertisers.

6. Changes to This Privacy Policy
We may update this Privacy Policy from time to time. Any changes will be reflected with an updated date at the top of this document.
